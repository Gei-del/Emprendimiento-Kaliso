## Administración del catálogo

El proyecto incluye un panel protegido para gestionar productos sin modificar código. Desde allí se pueden:

- Publicar nuevos productos con fotografía.
- Registrar nombre, categoría, descripción, precio y tallas o tamaños.
- Mostrar u ocultar productos.
- Eliminar productos que ya no estén disponibles.

El acceso se encuentra en **“Administrar catálogo”**, al final del sitio.
